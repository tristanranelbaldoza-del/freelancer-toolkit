# Security Policy

## Reporting a Vulnerability

If you find a security issue in this plugin, please do not open a public GitHub issue.

Instead, email: 278107158+tristanranelbaldoza-del@users.noreply.github.com

Include:
- A description of the vulnerability
- Steps to reproduce it
- Potential impact

You can expect a response within 72 hours. If the issue is confirmed, a fix will be prioritized and you will be credited in the release notes.
